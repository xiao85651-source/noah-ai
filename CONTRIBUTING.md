# Contributing to Noah

The repository is currently a private research snapshot. Invitations and eventual public access are managed by the owner. Do not claim that a global volunteer network is already operating.

Useful first contributions:

- Reproduce CPU training and report environment, corpus hash and measured validation loss.
- Test CUDA contribution on hardware you own or are explicitly authorized to use.
- Improve multilingual interface copy, keyboard access and right-to-left layout.
- Add original or appropriately licensed text, with provenance and language labels, while keeping validation data separate.
- Improve checkpoint recovery, task verification, bandwidth use, resource controls and device monitoring.

Before sending a change, run Python and JavaScript tests. Never commit personal chats, keys, invite tokens, logs, private datasets or virtual environments. Keep model-quality claims tied to reproducible evaluations.

Contribution means voluntary participation. Stop the client whenever you choose. Current clients do not detect idle state, temperature or battery level; do not leave them unattended without evaluating device conditions.

The owner has not yet selected a public license or contributor terms. Do not submit third-party material whose rights are unclear. A future public contribution process needs explicit licensing before accepting broad external work.
