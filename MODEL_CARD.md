# Noah Seed — model card

- **Owner/maintainer:** repository owner `xiao85651-source`.
- **Purpose:** verify independently trained language-model weights and a voluntary compute protocol.
- **Stage:** seed research; not an instruction-following assistant.
- **Research direction:** biopharma, science/technology and code generation. The separate `research-v1` random-initialized experiment uses 48 original development records; after 40 CPU updates its six task probes still score 0/6. It is not a specialist model and does not replace the browser serving release. See `RESEARCH.md`.
- **Architecture:** independently implemented conventional decoder-only causal Transformer; 644,608 parameters; 3 layers, width 128, 4 heads, context 128.
- **Tokenizer:** 259 IDs: 256 UTF-8 bytes and BOS/EOS/PAD. Unicode text round trips without unknown-language characters at the tokenizer layer.
- **Initialization:** random, manual seed 17. No third-party pretrained weights.
- **Data:** original project-authored `training/corpus.jsonl`; separate `train` and `validation` documents in zh/en/ja/es/ar. No web crawl, user chat or personal files are used.
- **Objective:** next-byte prediction. Optimizer AdamW, learning rate 0.0006, weight decay 0.01, gradient norm clipping 1.0.
- **Verified seed run:** 100 CPU steps; held-out average cross entropy 5.5832389832 → 3.1773824215. These metrics measure the tiny authored corpus only and are not comparable to another model's score unless tokenizer, data and evaluation are identical.
- **What was tested:** CPU training and inference; causal masking; safe tensor transport; contributor identity separation; real gradient updates and checkpoint recovery; multilingual token encoding. CUDA execution was not tested.
- **Current limitations:** extremely small training corpus and parameter count; no general knowledge, alignment, robust conversation, factual reliability or demonstrated language proficiency. Generated bytes can form invalid UTF-8 and show replacement characters. Outputs should be treated as research artifacts.
- **Ownership/provenance:** project-created implementation and independently trained weights. Standard algorithms and dependencies retain their respective rights. Public licensing and contributor terms are pending owner selection.
- **Costs:** volunteers still pay device, electricity and network costs. Coordination and public inference require ongoing resources; there is no claim of unlimited zero-cost service.
