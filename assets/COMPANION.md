# Interface companion

The generated application asset is `public/companion.png` (1024 × 1536 RGBA). It uses actual alpha transparency. It was created with the built-in image generation tool from the owner's visual reference; it is not a pretrained language model component.

Generation brief: create an adult silver-haired fantasy companion inspired by the reference's blue crystal crown, blue eyes, ornate navy and white palette, and flowing hair. Full-body welcoming pose, dignified expression, fully covered opaque ceremonial gown, high collar and long sleeves. Keep the complete silhouette in frame on a transparent background. No scenery, lettering, logo or watermark.

The app supplies a gentle CSS breathing motion, a greeting, a pause control, reduced-motion support and a collapsible panel. This is a single illustrated asset with CSS animation, not a rigged Live2D character or frame animation. Greetings are interface copy and are separate from Noah's generated text.

The owner's source image is not included in the repository. Review asset rights and attribution before a public release.
